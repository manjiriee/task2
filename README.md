 Unemployment Analysis with Python

 Project Overview
This project analyzes unemployment rate data to understand trends and the impact of Covid-19 on unemployment levels.

The dataset was provided as part of the internship task.

 Technologies Used
- Python
- Pandas
- Matplotlib
- VS Code

 Steps Performed
1. Loaded the unemployment dataset.
2. Cleaned and preprocessed the data.
3. Converted the date column into datetime format.
4. Compared Pre-Covid and During/Post-Covid unemployment trends.
5. Created visualizations to identify patterns and changes.

Key Insights
- Unemployment rates increased significantly during the Covid period.
- Clear trend changes were observed after March 2020.
- Visualization helped understand economic impact.

 How to Run the Project
1. Install required libraries:
   pip install pandas matplotlib
2. Run the Python file:
   python unemployment_analysis.py

 Conclusion
